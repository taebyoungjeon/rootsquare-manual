# 루트스퀘어 운영 매뉴얼

직원들이 항목별로 찾아볼 수 있는 루트스퀘어 내부 운영 매뉴얼 위키입니다.

## 구성

- 음료 제조
- 오픈·클로즈
- 고객 응대
- 파트타이머
- 위생·청소
- 재고·발주
- 장비 유지보수

## 배포

GitHub Pages에서 `main` 브랜치의 루트 폴더를 배포 대상으로 설정하면 `index.html`이 첫 화면으로 열립니다.

## 근무 시간표 Google Sheet 연동

`schedule-data.js`의 `SCHEDULE_SHEET_CONFIG.csvUrl`에 Google Sheet CSV 공개 주소를 넣으면, 사이트가 해당 시트를 우선 불러와 근무 시간표를 갱신합니다. 주소가 비어 있거나 시트를 불러오지 못하면 기존 예시 화면을 보여줍니다.

권장 시트 컬럼:

```csv
날짜,요일,시간,상태,정규직,파트타이머,역할,변경일,변경내용
2026-06-17,수,08:00-10:00,오픈 준비,정규직 A/정규직 B,파트타이머 A,베이커리/카페 오픈,2026-06-12,파트타이머 출근 시간 조정
```

Google Sheet에서 `파일 > 공유 > 웹에 게시`를 선택하고, 게시 형식을 `CSV`로 만든 뒤 생성된 링크를 사용합니다.

## 오픈·마감 체크 제출

매뉴얼 첫 화면의 오픈·마감 체크리스트는 Google Apps Script 웹앱으로 제출하도록 구성되어 있습니다.

1. Google Sheet를 새로 만들고 이름을 `루트스퀘어 체크리스트 제출 기록`처럼 정합니다.
2. `확장 프로그램 > Apps Script`를 열고 `apps-script/checklist-submit.gs` 내용을 붙여 넣습니다.
3. `ADMIN_EMAILS`의 `manager@example.com`을 실제 관리자 이메일로 바꿉니다.
4. `배포 > 새 배포 > 웹 앱`을 선택합니다.
5. 실행 권한은 본인, 액세스 권한은 필요에 따라 `모든 사용자` 또는 조직 설정에 맞게 지정합니다.
6. 생성된 웹앱 URL을 `index.html`의 `window.CHECKLIST_SUBMIT_URL` 값에 넣습니다.

제출 기록은 시트의 `체크리스트 제출 기록` 탭에 쌓이고, 미체크 항목이 있으면 이메일 제목에 `[주의]`가 붙습니다.

### 체크리스트 항목 관리

Apps Script의 `doGet?action=config` 기능은 같은 Google Sheet 안의 `체크리스트 항목 관리` 탭을 읽어 오픈·마감 체크 항목을 구성합니다. 탭이 없으면 첫 호출 때 자동 생성됩니다.

관리 컬럼:

```csv
구분,순서,항목,중요,사용
오픈,1,북카페 옆문을 열었습니다.,Y,Y
마감,1,스템가든 회전문 잠금 상태를 확인했습니다.,Y,Y
```

- `구분`: `오픈` 또는 `마감`
- `순서`: 화면에 표시될 순서
- `항목`: 직원이 체크할 문장
- `중요`: 중요 항목이면 `Y`, 아니면 빈칸
- `사용`: 화면에 보이면 `Y`, 숨기려면 빈칸 또는 `N`
